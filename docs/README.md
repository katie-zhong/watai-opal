# Static demo

This folder is a zero-backend walkthrough of WAT.ai Ops with mock data. GitHub Pages serves it from here.

- `index.html` — the interactive demo (open directly in any browser)
- `demo.css` + `assets/fonts/` — styling and the IBM Plex typefaces, self-contained (no Google Fonts dependency)
- `screenshots/` — PNGs used in the root README, rendered from these same views

It is intentionally separate from the real app in `src/`, which runs on Next.js + Supabase.
